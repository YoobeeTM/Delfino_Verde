# Il Delfino Verde

Sito statico del ristorante, in italiano e inglese.

- `ildelfinoverde.html` contiene la pagina e le traduzioni.
- `index.html` reindirizza alla pagina principale per l'apertura del sito dalla radice di GitHub Pages.
- `Logo/LogoDelfino.png` è il logo locale usato nell'intestazione.
- `images/ristorante-esterno.jpg` è la foto principale della pagina.

Le cartelle dell'applicazione prenotazioni e i documenti Word non vengono inclusi nella repository pubblica.

## Pubblicazione

Repository pubblica: https://github.com/YoobeeTM/ristorante-il-delfino-verde  
Sito online: https://yoobeetm.github.io/Delfino_Verde/ildelfinoverde.html

Il workflow in `.github/workflows/pages.yml` pubblica automaticamente il sito su GitHub Pages a ogni push sul branch `main`. Per le modifiche future, lavora in questa cartella e invia i commit a `origin/main`.
